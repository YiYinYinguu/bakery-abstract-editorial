# Examples

Each folder contains the complete three-stage artifact set:

- `source.jpg` — unchanged source photograph
- `abstract-panel.png` — approved standalone abstraction
- `editorial.webp` — final vertical diptych

Source JPEGs have been stripped of EXIF, XMP, IPTC, and other private capture metadata while retaining their ICC color profiles. The composition script writes PNG; the WebP files here are lightweight repository previews of the final composites.
